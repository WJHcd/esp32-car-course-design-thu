# task2 摄像头巡线接线说明（ESP32-S3 ↔ USB 摄像头 + 超声波 + 电机 + TFT）

> 2026-09-08：接线不变，避障横移现在使用 GPIO12/14/16 三路编码器原始脉冲做
> 停转检测和有限轮速比例修正，已不只是测速显示。缺失/持续零脉冲会进入
> `AVOID_HOLD` 停车，不能通过拔掉编码器继续运行横移。三路脉冲/轮圈须一致；
> 现有 RPM 的 PPR=20 为占位值，不能据此认定真实轮速。T 形停车确认后启动推球。
> 详细调试见 [路线锁定与避障调试](ROUTE_LOCK.md)，以下历史数值以源码为准。

> 任务二：赛道与任务一相同，**巡线改用 USB 摄像头（UVC）**，避障仍用 HC-SR04 超声波。
> 相对任务一（task1_ver2.0）的改动：**拆除红外模块全部接线，腾出资源接摄像头**；
> 电机/编码器/TFT/超声波接线全部沿用，无需改动。

## 2. 新增接线：USB 三合一摄像头（JQ-CAM12-720P）

摄像头为 **USB UVC 设备**（4Pin：5V / GND / D− / D+），必须接 ESP32-S3 的 **USB Host 引脚 GPIO19/20**。

| 摄像头引脚 | ESP32-S3 | 说明 |
| --- | --- | --- |
| D− (D-) 白| **GPIO19** | USB 数据负 ⚠️ 与 D+ 不可接反 |
| D+ (D+) 红 | **GPIO20** | USB 数据正 |
| 5V 黄| 5V 电源 | ⚠️ 建议取自电池稳压输出（D24A 同源 5V），勿从电脑 USB 口取电跑车 |
| GND 黑| GND | 共地 |

### ⚠️ 关键影响：板载 USB 口被占用

GPIO19/20 就是**板载 USB 座的数据脚**。接上摄像头后：

- **烧录/监视不能再走板载 USB 口**
- 两种方案：
  - **方案 A（推荐）**：外接 USB 转 TTL → UART0
    - TTL_TX → GPIO44（ESP32 RX）
    - TTL_RX → GPIO43（ESP32 TX）
    - GND → GND（共地）
    - 波特率 115200；烧录时按住 BOOT 再短按 EN 进下载模式
  - **方案 B（临时）**：平时拔下摄像头杜邦线、插回板载 USB 烧录；跑车前再换回摄像头

## 4. 上电顺序

1. 接好全部信号线并共地
2. ESP32-S3 由 USB-TTL（或临时板载 USB）供电
3. 电池给 D24A 和摄像头 5V 供电
4. 先 USB 后电池；断电顺序相反

## 5. 运行模式（main.c 顶部 `TASK2_MODE`）

| 值 | 模式 | 说明 |
| --- | --- | --- |
| 0 | 综合模式 | 摄像头巡线 + 超声避障，正式跑车 |
| 1 | 摄像头巡线测试 | 打印黑线误差 err（左负右正），不驱动电机 |
| 2 | 超声标定统计 | 每 10 次测量输出均值/极差，验证误差<5cm |
| 3 | 平移方向自检 | 着地短脉冲观察左移/右移/前进 |
| 4 | TFT 面板自检 | 红绿蓝黑循环 |
| 5 | 摄像头 TFT 预览 | 将解码画面缩放显示到 TFT，不驱动电机 |
| 6 | 摄像头 ASCII 预览 | 每秒向 UART0 打印 64×24 字符画，不驱动电机 |
| 7 | 摄像头纯巡线实车测试 | 只启用摄像头和电机，不初始化超声/编码器/TFT；弯道丢线后按最后侧别原地找线 |

## 6. 待标定项

1. **虚拟红外扫描带**（camera_line.h）：`CAM_SCAN_CENTER_FROM_BOTTOM_PCT=60` 表示扫描带中心距画面底部 60%，`CAM_SCAN_BAND_HEIGHT_PCT=8` 表示扫描带高度为画面高度的 8%，`CAM_SCAN_WIDTH_PCT=60` 表示使用画面中央 60% 的宽度。摄像头俯角调整后，先用 MODE=6 确认车前目标黑线会穿过这条扫描带；扫描带不应落在轮子或车体上。
2. **黑线亮度阈值** `CAM_BIN_THRESHOLD`（camera_line.h，当前 120）：MODE=6 中黑线应显示为 `#`，白底不应大面积显示 `#`；环境整体变亮时可适当调大，误把阴影判成黑线时应调小。
3. **T 线判定**：一行黑色覆盖扫描窗口至少 `CAM_WIDE_ROW_PCT=45%` 才算宽黑行；至少 `CAM_T_LINE_MIN_WIDE_ROWS=3` 行命中构成候选。首帧候选立即停车，静止确认第二帧后进入 `FINISH_STOP`。
4. **摄像头误差阈值** `CAM_ERR_BIG`（walking.c，当前 0.45）：直角弯前 |err| 达到多少触发大转向。
5. **编码器 PPR**（encoder.c，当前 20 占位）：架空让轮子转 10 圈数脉冲 N，PPR=N/10

> 综合模式（MODE=0）启动后会先等待摄像头连续稳定见线，再使能电机；摄像头枚举、开流或未对准赛道期间，小车应保持刹车状态。

> MODE=7 用来隔离巡线和避障：它不初始化、不读取超声，但会调用 `walking_update_cam(..., ULTRASONIC_INVALID, ...)`，因此只运行巡线所需的 RUN / CORNER_SEARCH / LINE_SEARCH。外侧见线时先减速大转，拐角短暂丢线后停止前进并原地找线，不会执行超声避障动作。

> MODE=7 当前直线最高 15%、普通最低 10%、弯道前进 10%、原地找线转向 15%，避免 7%～8% 输出落入实车电机静摩擦死区。
