# task1_ver2.0 · 超声波避障设计文档（硬编码平移式）

> 版本：2026-08-27
> 目标：把 task1_ver2.0 现有的**转向式**避障
> （`STOP → BACKUP → TURN_OUT → BYPASS → TURN_BACK → FIND_LINE`）
> 改为**平移式**硬编码避障：
>
> ```
> 超声检测到前方障碍 → 向左平移 T1 → 直行前进 T2 → 向右平移 T3 → 找回黑线 → 恢复循迹
> ```
>
> 赛道简单，各阶段**时长与速度全部硬编码**（`walking.c` 顶部 `#define`），实车微调。

---

## 0. 设计原则（重要）

**避障只做避障，不影响现有循迹。** 具体要求：

1. 循迹相关逻辑（`RUN` / `LINE_SEARCH` / `CORNER_SEARCH` 的状态机分支、PD 参数、
   低通滤波、死区、方向投票、锐角找线出口确认等）**一律不改动**。
2. 避障只替换自己的一组 `AVOID_*` 状态，`FAILSAFE_STOP` 与其自动恢复逻辑保持不变。
3. 循迹调用三轴混控时 `strafe=0`，因此**三轮输出与现状完全一致**，循迹行为零变化。
4. 三轴混控是向后兼容的扩展：新增第三参数，不改原有 forward/turn 的映射关系。

---

## 1. 检测逻辑（复用现有，不改）

沿用 `walking.c` 的 `obstacle_confirmed()`：

| 项 | 值 | 说明 |
| --- | --- | --- |
| `OBSTACLE_TRIGGER_CM` | 18 | 距离 ≤18cm 计一个"障碍样本" |
| `OBSTACLE_CLEAR_CM` | 24 | 距离 ≥24cm 清空样本计数 |
| `OBSTACLE_CONFIRM_SAMPLES` | 2 | 间隔 `OBSTACLE_SAMPLE_GAP_MS`(350ms) 内累计 2 样本确认 |
| 生效状态 | 仅 `RUN` / `LINE_SEARCH` | 旋转中/避障中不重复触发 |

确认后进入 `AVOID_STOP`。

## 2. 避障状态机（硬编码时序）

```
RUN ──(obstacle_confirmed)──► AVOID_STOP ──(120ms)──► AVOID_STRAFE_LEFT ──(T1)──►
AVOID_FORWARD ──(T2)──► AVOID_STRAFE_RIGHT ──(T3)──► AVOID_FIND_LINE ──(见线)──► RUN
                                                          │(1800ms 超时)
                                                          ▼
                                                      FAILSAFE_STOP（自动恢复）
```

### 2.1 时序参数（硬编码初值）

| 状态 | 参数 | 初值 | 动作 |
| --- | --- | --- | --- |
| `AVOID_STOP` | `AVOID_STOP_MS` | 120ms | 确认后短暂停车，避免直撞障碍 |
| `AVOID_STRAFE_LEFT` | `AVOID_STRAFE_LEFT_MS` | **800ms** | 向左平移 |
| `AVOID_FORWARD` | `AVOID_FORWARD_MS` | **500ms** | 直行前进，越过障碍 |
| `AVOID_STRAFE_RIGHT` | `AVOID_STRAFE_RIGHT_MS` | **800ms** | 向右平移，回原车道 |
| `AVOID_FIND_LINE` | `AVOID_FIND_LINE_MS` | 1800ms | 前进+小幅扫描找回黑线；超时进故障停车 |
| — | `AVOID_STRAFE_SPEED_PCT` | 12% | 平移速度 |
| — | `AVOID_FORWARD_SPEED_PCT` | 15% | 前进速度 |
| — | `AVOID_FIND_SPEED_PCT` | 10% | 找线前进速度 |

> **时长约定：T1 = T3 = 800ms > T2 = 500ms**（左右平移时间大于前进时间，按需求调整）。
> 实车按赛道尺寸整体缩放即可（如均 ×1.5 或 ×0.8），保持左/右 > 前进的关系。

### 2.2 方向约定

- `strafe > 0` = **向左平移**，`strafe < 0` = **向右平移**（见第 3 节标定）。
- 平移阶段不回读超声波（硬编码，不做自适应）。
- 平移期间若已偏离黑线，`AVOID_FIND_LINE` 会沿前进方向小幅转向扫描找回，不依赖位置记忆。

## 3. 运动学扩展（三轴混控）

### 3.1 现状

`apply_body_command(int forward, int turn)` 只有两轴：

```
L = FORWARD_SIGN_L·fwd + TURN_SIGN_L·turn
R = FORWARD_SIGN_R·fwd + TURN_SIGN_R·turn
B = (TURN_SIGN_B·turn)·TURN_B_GAIN
```

没有横向（平移）分量，车辆无法横移。

### 3.2 扩展为三轴

```c
static void apply_body_command(int forward, int turn, int strafe)
{
    wheel[L] = FORWARD_SIGN_L*forward + TURN_SIGN_L*turn + STRAFE_SIGN_L*strafe;
    wheel[R] = FORWARD_SIGN_R*forward + TURN_SIGN_R*turn + STRAFE_SIGN_R*strafe;
    wheel[B] = (TURN_SIGN_B*turn)*TURN_B_GAIN + (STRAFE_SIGN_B*strafe)*STRAFE_B_GAIN;
    ...（等比缩放 + 输出，逻辑不变）
}
```

- 循迹调用处一律传 `strafe=0` → 输出与现状**逐位一致**，不影响循迹。
- 新增待标定常数（初值按三轮全向对称猜测）：

```c
#define STRAFE_SIGN_L  (+1)
#define STRAFE_SIGN_R  (+1)
#define STRAFE_SIGN_B  (-1)
#define STRAFE_B_GAIN  2.0f   /* 120° 几何：纯平移时 B 轮转速 ≈ 2×L/R（L:+v,R:+v,B:-2v） */
```

> 依据：前进标定（`L=-v, R=+v, B=0`）与 120° 三轮全向几何一致，故平移分量
> 按同一几何取 `L:+v, R:+v, B:-2v`（B 反向且约为 L/R 的 2 倍）。

### 3.3 标定（必须做）

> ⚠️ **不要架空轮子判断方向**：架空时车体不动，只能看到轮子转向，而本车的
> 「左移」与「原地左转」在轮子上几乎一样（都是 L/R 同向、B 反向），肉眼无法区分。
> 正确做法是**轮子着地、短促脉冲**，直接看车体实际位移。

`TASK1_MODE=5` 已改为短脉冲（约 0.4s，位移几厘米），在宽敞地面/桌面**着地**运行：

1. 左移脉冲：车体应**向左平移**（不旋转、不前/后）。
2. 若左移时车体实际**向右** → 翻转 `STRAFE_SIGN_L` 和 `STRAFE_SIGN_R`（B 不变）。
3. 若左移时车体**原地旋转** → 翻转 `STRAFE_SIGN_B`。
4. 若平移带明显旋转/斜走 → 微调 `STRAFE_B_GAIN`（1.5~2.5）或 `AVOID_STRAFE_SPEED_PCT`。

也可以直接用 `TASK1_MODE=0` 放障碍物实测：避障左移阶段走反就按上表取反（低速、小障碍）。

## 5. 测试计划

1. **TASK1_MODE=5（平移自检）**：架空轮子，确认左/右/前进方向与常数；不对就翻转。
2. **TASK1_MODE=3（行走状态机自检）**：确认新避障流程能走通到 RUN（不驱动电机）。
3. **TASK1_MODE=4（仅红外巡线）**：确认循迹行为与改动前一致（回归）。
4. **TASK1_MODE=0（综合模式）**：赛道实测——放障碍验证左移→前进→右移→找回黑线。

---

## 6. 风险与注意事项

- **平移方向常数是初始猜测**，未标定前**绝不可**在综合模式下实跑避障，否则车会横移到错误方向。
- 时长/速度均为近似值，先低速、小障碍验证。
- 电机低于约 8%~10% 可能因静摩擦不动，平移速度不要一味调低。
- `AVOID_FIND_LINE` 依赖黑线仍在可扫描范围内；若平移量过大导致彻底丢线，会超时进 `FAILSAFE_STOP`（停车 5 拍见线自动恢复，非死锁）。
