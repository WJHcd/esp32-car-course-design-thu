# task1 接线说明（ESP32-S3 ↔ 红外循迹 + 超声波）

> 任务一：把参考 STM32 程序（Car_main.c）拆成 **红外检测 / 超声检测 / 行走策略** 三个模块，
> 在 ESP32-S3 上实现"循迹 + 超声波避障"。电机接线沿用 `motor-drive-test`（已在车上接好）。

---

## 1. 本任务新增接线（相对 motor-drive-test 多出 6 根）

### 四路红外循迹 LQ-R4CHV（数字量，OUT1~OUT4）

| LQ-R4CHV 引脚 | ESP32-S3 GPIO | 对应参考程序 |
| --- | --- | --- |
| OUT1 | **GPIO3** | sensor1 → d |
| OUT2 | **GPIO0** | sensor2 → a |
| OUT3 | **GPIO21** | sensor3 → b |
| OUT4 | **GPIO39** | sensor4 → c |
| VCC | 3V3（或 5V，看模块丝印） | — |
| GND | GND | — |

> ⚠️ GPIO0 是板上 BOOT 按键（带内部上拉），本任务只接 **红外输出**（输入方向），安全。
> ⚠️ GPIO39 是芯片 JTAG 脚，默认可当普通 GPIO 用；若以后开 JTAG 调试需换脚。
> 极性：默认"检测到黑线 = 低电平"（`IR_LINE_LEVEL 0`），实测相反改 `pins.h`。

### HC-SR04 超声波（TRIG / ECHO）

| HC-SR04 引脚 | ESP32-S3 GPIO | 说明 |
| --- | --- | --- |
| TRIG | **GPIO18** | 触发，发 10µs 高电平 |
| ECHO | **GPIO40** | 回波，高电平宽度=距离 |
| VCC | 5V | HC-SR04 需要 5V |
| GND | GND | 共地 |

> ⚠️ GPIO40 同 GPIO39，JTAG 脚，默认可用。

## 2. 上电顺序

1. 先接好全部信号线 + GND 共地
2. ESP32-S3 用 **USB 供电**（插电脑，方便 `idf.py monitor`）
3. D24A 电机板与红外/超声波模块用电池供电（电机母线 Vin+ / Vin-）
4. 上电顺序：先 USB，后电池

> 只测红外/超声波时不必给 D24A 供电；跑行走策略/综合模式才需要。

---

## 3. 运行模式切换（main.c 顶部 `TASK1_MODE`）

| 值 | 模式 | 说明 | 需要供电 |
| --- | --- | --- | --- |
| 0 | 综合模式 | 循迹 + 超声波避障，正式跑车 | USB + 电池 |
| 1 | 红外检测测试 | 串口打印 OUT1~4 / a b c d | USB（+红外模块电源） |
| 2 | 超声检测测试 | 串口打印距离 | USB（+模块电源） |
| 3 | 行走策略自检 | 喂合成数据跑状态机，**不驱动电机** | USB（无需电池） |

改完 `#define TASK1_MODE x` 后重新编译烧录即可。

## 5. 模块文件说明

| 文件 | 功能 |
| --- | --- |
| `infrared.h/.c` | 红外检测：`infrared_init()` / `infrared_read()` / `infrared_all_black()` |
| `ultrasonic.h/.c` | 超声检测：`ultrasonic_init()` / `ultrasonic_measure_cm()` |
| `walking.h/.c` | 行走策略：状态机（RUN/MEET_FACE/避障/旋转…）+ PID，`walking_update()` |
| `motor.h/.c` | 底层电机驱动（D24A 3×TB6612FNG），从 motor-drive-test 移植 |
| `pins.h` | 红外/超声波引脚集中定义，方便改线 |
| `test_infrared.c` | 红外测试 |
| `test_ultrasonic.c` | 超声测试 |
| `test_walking.c` | 行走策略状态机自检（安全，不驱动电机） |
| `main.c` | 综合：20ms 控制循环，`TASK1_MODE` 切换模式 |

## 6. 待标定项（第一次上电时）

1. **红外极性**：黑线是低还是高（看 test_infrared 打印，改 `pins.h` 的 `IR_LINE_LEVEL`）
2. **左右顺序**：a/b/c/d 与物理左右是否一致（不一致改 `infrared.c` 的映射）
3. **电机方向**：正转/反转是否与 L/R/B 语义一致（改 `walking.c` 的 `WHEEL_TO_MOTOR_*`）
4. **PID/速度**：`walking.c` 里 `s_kp` 与速度 800/1000 按实际车感微调
