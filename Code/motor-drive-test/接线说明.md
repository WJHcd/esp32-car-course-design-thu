# motor-drive-test 接线与使用说明

> 适用：ESP32-S3-DevKitC-1 + D24A + 3×LQ25R8V6。
> 本程序只做三路电机/编码器诊断，不验证直线、转弯或全向运动学。

## 1. 上电前的强制安全条件

- 小车必须垫高，三个轮子均不能接触桌面或地面。
- 所有插拔、交换端口和改线都必须在 USB 与 D24A Vin 均断电后进行。
- 先用万用表确认 DC-DC 输出；首次测试建议约 5~6V，不要按“可能是 12V”直接上电。
- ESP32-S3 使用 USB 供电时，D24A 的 5V、3V3 均不要接到 ESP32；两板只共地并连接信号线。
- 如果 D24A 上有 `STBY-3V3` 跳线帽，采用 GPIO1 控制 STBY 前必须取下跳线帽。
- 电机或驱动芯片明显发热、冒烟、有异味、线材发软时立即断开 D24A Vin。

## 2. 推荐供电方式

| 设备 | 供电 | 与另一块板的电源连接 |
| --- | --- | --- |
| ESP32-S3-DevKitC-1 | USB | 不连接 D24A 5V/3V3 |
| D24A | DC-DC → Vin+/Vin- | 只连接公共 GND |

必须连接：

```text
ESP32 GND ───────── D24A GND
```

禁止连接（ESP32 正由 USB 供电时）：

```text
ESP32 5V  ╳──────── D24A 5V
ESP32 3V3 ╳──────── D24A 3V3
```

否则可能造成两个稳压输出互相回灌。

## 3. STBY 只能二选一

推荐采用软件控制：

1. 断开全部电源；
2. 取下 D24A 上可能存在的 `STBY-3V3` 跳线帽；
3. ESP32 GPIO1 接 D24A STBY；
4. 新固件初始化时保持 STBY 低，仅在倒计时结束后使能，测试完成后再次拉低。

另一种是固定使能：STBY 用跳线帽接 D24A 3V3，此时不要连接 GPIO1。固定使能不适合本诊断程序的安全流程。

板上 `SW` 拨动开关更可能是电源开关，不能在未测通断关系时把它当成 STBY。

## 5. 新诊断固件的运行流程

固件不会无限重复驱动电机，只运行一轮：

1. 初始化 GPIO、PWM、PCNT，STBY 保持低；
2. 进入 15 秒手动编码器窗口：用手依次转 A/B/C 轮，串口同时显示三个计数；
3. 再倒计时 5 秒；
4. STBY 拉高；
5. A 正转 25% 1 秒、A 反转 25% 1 秒；
6. B 正转/反转；
7. C 正转/反转；
8. STBY 拉低，保持禁用；
9. 如需重测，按 RESET。

每段会同时打印：

```text
enc A=... B=... C=...
```

正常现象：

- 手转 A 时主要只有 enc A 连续变化；反向手转后符号相反；B/C 同理。
- 测试 motor A 时只应是 A 轮转、主要只有 enc A 变化；B/C 同理。
- 同一电机正反转时，对应编码器最终计数符号应相反。
- A/B/C 的绝对计数允许不同，但不应有某一路一直是 0 或只在 0/1 间跳。

## 6. C 不转时的快速隔离

已知 A、B 能转时，STBY、D24A 总电源和公共地大概率正常；优先检查 C 的专用链路：

```text
GPIO9→PWMC
GPIO10→CIN1
GPIO11→CIN2
D24A C 通道功率级
C 口 JST 6P
C 电机/线束
```

按以下顺序排查，每次换线前必须全部断电：

1. 运行到 C 阶段时测 GPIO10/11：正转应约为 3.3V/0V，反转应约为 0V/3.3V。
2. 测 GPIO9/PWMC：万用表会看到约 0.8V 的平均值（25% PWM），示波器/逻辑分析仪应看到约 20kHz、3.3V PWM。
3. 对比 ESP32 引脚端与 D24A 排针端；ESP32 有信号而 D24A 端没有，说明杜邦线/排针接触有问题。
4. 断电后交换 A、C 两个完整 JST 6P 电机插头：
   - 原 C 电机接 A 口后能转：C 电机/线束基本正常，查 D24A C 控制或功率通道；
   - 原 C 电机接 A 口后仍不转：查 C 电机、JST 线束或机械卡死；
   - 原 A 电机接 C 口也不转：进一步证明故障在 C 控制/驱动通道。
5. 用已知正常的 A 控制信号测试 C 功率通道：断开原 C 控制线，将 GPIO2/4/5 分别接 PWMC/CIN1/CIN2，运行程序的 A 阶段：
   - C 口电机能转：D24A C 功率级正常，查 GPIO9/10/11 或原 C 三根控制线；
   - C 口仍不转：D24A C 功率级、C 输出口或 PCB 更可疑。
6. 反向验证 GPIO9/10/11：将它们接到已知正常的 PWMA/AIN1/AIN2，运行程序的 C 阶段：
   - A 口电机能转：ESP32 的 C PWM/方向代码和 GPIO 正常，D24A C 通道故障概率高；
   - A 口仍不转：查 GPIO9/10/11 接线、焊点或开发板引脚。

不要在带电状态交换 A/C 口，也不要让 A、C 两组 ESP32 输出同时接到同一 D24A 输入。
