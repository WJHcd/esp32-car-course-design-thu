# motor-drive-test 接线说明（ESP32-S3 ↔ D24A 驱动板）

> 固件已烧录，引脚分配如下。**接线前请断开 D24A 的电机电源（Vin）**，接好信号线、确认无误后再上电。

---

## 1. 电源与共地（先接这个！）

| ESP32-S3 (DevKitC-1) | D24A 板 | 说明 |
| --- | --- | --- |
| **GND**（任意 GND 排针） | **GND**（控制排针上的 GND） | ⚠️ **必须共地**，否则所有信号无效 |
| 5V（板载 USB 供电即可） | 5V（可选） | 测试时板子用 **USB 线供电**最简单；也可用 D24A 5V 端子（需确认 LDO 电流足够，≥500mA） |

> 推荐：测试阶段 **ESP32-S3 用 USB 供电**（插着电脑），D24A 单独用电池供电，两者只连 GND 共地 + 信号线。

---

## 4. 上电顺序（重要！）

1. **先接好所有信号线 + GND 共地**
2. 确认 D24A 板上 **SW 拨动开关 = ON**（STBY 使能）
3. 先给 **ESP32-S3 供电**（USB），确认串口能打印
4. 再给 **D24A 供电**（电池 → Vin+/-）
5. 观察电机依次转动

## 5. 测试现象（预期）

- 每 2 秒切换：`A正转 → B正转 → C正转 → A反 → B反 → C反 → 三电机同正转 → 三电机同反转`
- 串口每 200ms 打印 `enc0/enc1/enc2` 编码器计数，转动时计数应递增/递减
- 若某电机不转：查该电机 PWMA/B/C 与 IN1/IN2 接线、JST 6P 是否插紧
- 若方向反了：交换该电机 IN1/IN2 两根线（或软件取反）
