# task2 摄像头巡线接线说明（ESP32-S3 ↔ USB 摄像头 + 超声波 + 电机 + TFT）

> 任务二：赛道与任务一相同，**巡线改用 USB 摄像头（UVC）**，避障仍用 HC-SR04 超声波。
> 相对任务一（task1_ver2.0）的改动：**拆除红外模块全部接线，腾出资源接摄像头**；
> 电机/编码器/TFT/超声波接线全部沿用，无需改动。

---

## 1. 拆除的接线（红外模块 LQ-R4CHV 全部断开）

| 原接线 | 原 GPIO | 处理 |
| --- | --- | --- |
| OUT1 | GPIO18 | 拆除，悬空 |
| OUT2 | GPIO21 | 拆除，悬空 |
| OUT3 | GPIO41 | 拆除，悬空 |
| OUT4 | GPIO42 | 拆除，悬空 |
| VCC | 3V3/5V | 拆除 |
| GND | GND | 拆除 |

> 红外巡线功能由摄像头黑线质心检测替代（`camera_line.c`），GPIO18/21/41/42 释放备用。

## 2. 新增接线：USB 三合一摄像头（JQ-CAM12-720P）

摄像头为 **USB UVC 设备**（4Pin：5V / GND / D− / D+），必须接 ESP32-S3 的 **USB Host 引脚 GPIO19/20**。

| 摄像头引脚 | ESP32-S3 | 说明 |
| --- | --- | --- |
| D− (D-) | **GPIO19** | USB 数据负 ⚠️ 与 D+ 不可接反 |
| D+ (D+) | **GPIO20** | USB 数据正 |
| 5V | 5V 电源 | ⚠️ 建议取自电池稳压输出（D24A 同源 5V），勿从电脑 USB 口取电跑车 |
| GND | GND | 共地 |

### ⚠️ 关键影响：板载 USB 口被占用

GPIO19/20 就是**板载 USB 座的数据脚**。接上摄像头后：

- **烧录/监视不能再走板载 USB 口**
- 两种方案：
  - **方案 A（推荐）**：外接 USB 转 TTL → UART0
    - TTL_TX → GPIO44（ESP32 RX）
    - TTL_RX → GPIO43（ESP32 TX）
    - GND → GND（共地）
    - 波特率 115200；烧录时按住 BOOT 再短按 EN 进下载模式
  - **方案 B（临时）**：平时拔下摄像头杜邦线、插回板载 USB 烧录；跑车前再换回摄像头

## 4. 上电顺序

1. 接好全部信号线并共地
2. ESP32-S3 由 USB-TTL（或临时板载 USB）供电
3. 电池给 D24A 和摄像头 5V 供电
4. 先 USB 后电池；断电顺序相反

---

## 5. 运行模式（main.c 顶部 `TASK2_MODE`）

| 值 | 模式 | 说明 |
| --- | --- | --- |
| 0 | 综合模式 | 摄像头巡线 + 超声避障，正式跑车 |
| 1 | 摄像头巡线测试 | 打印黑线误差 err（左负右正），不驱动电机 |
| 2 | 超声标定统计 | 每 10 次测量输出均值/极差，验证误差<5cm |
| 3 | 平移方向自检 | 着地短脉冲观察左移/右移/前进 |
| 4 | TFT 面板自检 | 红绿蓝黑循环 |
