# 主板接口说明

**USB 三合一摄像头** | 集成摄像头 + 麦克风 + 喇叭

---

## 1. 外观视图

### 正面 / 反面
- **正面**：摄像头镜头居中，两侧对称布置安装孔
- **反面**：PCB 板，标注 `CAM12-720P-V2 30:22`

### 接口说明

| 接口 | 说明 |
|------|------|
| 🎤 麦克风接口 | 板载 MIC（2PIN1.25 座） |
| 🔊 喇叭接口 | 板载扬声器（2PIN1.25 座） |
| 📷 摄像头接口 | 4Pin 接口（USB 信号输出） |

### USB 引出线定义（5V / GND / D- / D+）

```
5V  GND
D-   D+
```
